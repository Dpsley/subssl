# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
[private security advisory form](https://github.com/Dpsley/subssl/security/advisories/new)
and include a concise reproduction path, affected versions, and impact.

Do not include live credentials, access tokens, internal hostnames, private IP
addresses, or customer data. We will acknowledge a valid report, investigate it,
and coordinate disclosure through the advisory.

## Supported versions

Security fixes are applied to the latest release on `main`. Upgrade to the most
recent GitHub Release before reporting an issue whenever possible.
